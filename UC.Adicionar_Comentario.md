Especificação de Caso de Uso:

Código / Nome do Caso de Uso: UC004 – Adicionar comentário

Ator Principal: Usuário

Resumo: O usuário precisa conseguir adicionar um comentário em uma obra disponível na Biblioteca Digital.

Pré-condições: O usuário deve estar acessando uma obra disponível no sistema.

Pós-condições: O comentário é registrado no sistema e fica associado à obra selecionada.

Fluxo Principal (Usuário – Sistema):

Usuário: Acessa uma obra na Biblioteca Digital.
Sistema: Exibe as informações da obra e os recursos disponíveis.
Usuário: Seleciona a opção de adicionar comentário.
Sistema: Exibe um campo para inserir o comentário.
Usuário: Digita o comentário desejado.
Usuário: Confirma o envio do comentário.
Sistema: Verifica se o comentário foi preenchido corretamente.
Sistema: Registra o comentário na obra.
Sistema: Exibe uma mensagem informando que o comentário foi adicionado com sucesso.

Fluxo Alternativo: Caso o usuário desista de adicionar o comentário antes de enviá-lo, ele seleciona a opção de cancelar. O sistema descarta o comentário digitado e retorna para a página da obra.

Fluxo de Exceção: Caso o usuário tente enviar o comentário sem preencher o campo, o sistema informa que é necessário escrever um comentário antes de continuar.
